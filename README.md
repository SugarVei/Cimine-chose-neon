# Cimine chose-neon

[打开手机 / 桌面实时体验](https://works.sugarv.mom/cimine-chose-neon/)

实时 WebGL 影院选座与第一人称观影视角预览网页。全界面由 HTML/CSS 绘制，影厅建筑、织物软包座椅、透视暖白灯带、射灯与银幕《AVENGERS: DOOMSDAY》主视觉均由代码程序化生成，自带离线 `three.min.js`，支持手机与桌面零外网依赖秒开。

## 交互体验

- **抓起连座换位**：按住蓝色连座可浮起拖动并跨过中央过道吸附至任意同排同侧连续空位（拖动时同步显示细蓝候选轮廓与悬浮提示胶囊，松手落位后更新底部座位信息）；也可直接点选空座或使用顶部票数胶囊增减 1–4 张连座。
- **4 秒连续飞入影厅**：点击 **Preview** 后，96 把 3D 实体椅子先与 2D 座位图逐一对齐（两块蓝色实体坐垫对应显影），随后相机沿平滑弧线从后上方推入所选连座的坐姿眼高，底部浮现半透明迷你座位图。
- **原位环顾与原路返回**：落座后横向拖动即可在原位左右转头环顾两侧暖白竖向灯带墙与银幕；点击迷你图可切换同排位置；点击 **Seats** 沿入场路径平滑退回并保留最新选座。

## 本地运行

直接用支持 WebGL 的现代浏览器打开 `index.html`（或通过任意静态服务器托管本目录）即可离线运行，无需构建或安装依赖。
